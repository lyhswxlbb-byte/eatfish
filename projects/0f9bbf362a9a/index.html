🎯 核心结论

品牌表现

  • ULIKE 与 GEMO 为样本主力（两者合计占比最高），素材数量领先其他品牌
  • ULIKE 泛进店成本处于样本区间低位、CPA3 同样偏低，投放效率整体最优
  • GEMO A3率处于样本区间偏高档位，内容渗透力强；泛进店成本偏高档，需搭配站内路径优化
  • 极萌（黄金微雕仪）在样本内量级偏小、但内容化程度高，A3率处于样本高位、CPA3 处于样本低位，属于高效率增量素材
  • Seayeo 样本量较少，单条 CPA3/A3率整体处于样本中位水平

素材共性

  • 核心素材形式：真人出镜 + 沉浸式vlog + 功能测评 / 剧情演绎为主流
  • 场景高度集中在 居家护肤（浴室 / 卧室 / 客厅），部分品牌加入职场、家庭情景剧
  • 钩子多用「效果前置」→「产品拆解」→「使用演示」→「效果验证」四段式结构
  • 核心卖点关键词：智能识别 · 分区护理 · 多部位适配（面部/唇部/身体）· 上妆服帖 · 皮贴骨

可复用打法

  • 「黄黑皮 / 敏感肌 / 皮薄部位 / 抗衰」等 肤质痛点 直击型钩子表现效率处于样本高档
  • 产品高价单件 → 通过「一机多用」演示放大性价比感知
  • 结尾必带「上妆前后 / 素颜效果 / 情绪反差」对比，助力主动搜索 + 泛进店
  • 泛进店成本处于样本低档的素材，以 场景切片型日常 vlog 与 轻剧情演绎 为主
